# Geluiden

Alle geluiden zijn mono 44.1 kHz 16-bit .wav en mogen vrij aangepast of vervangen worden.

**Na het aanpassen of toevoegen van een .wav:** dubbelklik `pack_sounds.bat` (in de map erboven).
Dat werkt `sounds_pack.js` bij, wat de game gebruikt als je de HTML gewoon dubbelklikt.
Op een webserver (bv. itch.io) laadt de game de .wav-bestanden rechtstreeks.

Varianten heten `naam_0.wav`, `naam_1.wav`, ... - de game kiest er willekeurig een. Je kan er gewoon extra bijzetten
(draai daarna `pack_sounds.bat`, ook als je via een webserver speelt: de lijst met namen komt uit het pack).
Ontbreekt een geluid, dan valt de game terug op een gesynthetiseerde versie (zo werken `hic` en `phone_buzz` nu).
